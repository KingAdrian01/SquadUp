# SquadUp 🚀

**SquadUp** ist eine moderne Web-App für Trinkspiele und Party-Games, die darauf ausgelegt ist, Menschen zusammenzubringen. Starte eine Lobby, teile den Code und spiele in Echtzeit mit deinem Squad.

### Aktuelle Features:
*   **Busfahrer:** Das komplette Karten-Trinkspiel inklusive 3 Runden (Ziehen, Pyramide & Finale).
*   **Real-time Multiplayer:** Dank Firebase Realtime Database werden Karten, Schlucke und Spielstände sofort auf allen Geräten synchronisiert.
*   **PWA Ready:** Kann direkt auf dem Home-Bildschirm installiert werden für ein natives App-Feeling ohne Browserleiste.
*   **No-Setup Join:** Einmaliger Link-Klick genügt – keine manuelle Konfiguration für Mitspieler nötig.

### Tech Stack:
*   **Frontend:** HTML5, Modern CSS (Flexbox/Grid), JavaScript (ES6+).
*   **Backend:** Firebase Realtime Database für die Live-Synchronisation.
*   **Deployment:** Vercel.
